# Photo to C4D Style

[English](README.en.md)

将用户上传的照片重建为精美、细腻的 C4D 风格 3D 模型。

这是一个 Codex Skill，适合把店铺、建筑、街景、物品、宠物或人物照片重新表现为完整的 3D 收藏模型，同时尽量保留原照片的主体、构图、视角和识别特征。

## 能做什么

- 将照片重建为完整的 C4D 风格 3D 模型，而不是简单套用滤镜
- 使用柔软橡胶、硅胶或 satin vinyl 材质
- 生成细腻微纹理、圆润倒角、柔和高光和精致的模型表面
- 使用明亮、干净的工作室级产品灯光
- 根据原图判断正面或斜侧视角，并保持平行透视
- 对接近正面的照片保持干净的正面或近正面模型视角
- 保留主体轮廓、关键物体、相对布局和可读招牌
- 在模型四周保留充足画布留白，避免主体贴边或被裁切

## 使用方式

在 Codex 中显式调用：

Use $photo-to-c4d-style to transform the uploaded photo into a polished C4D-style 3D model.

也可以直接用中文描述需求：

把这张照片转换成精美的 C4D 风格 3D 模型，使用细腻的软橡胶材质、工作室级灯光和充足留白。

## 视觉方向

- 精致的 Cinema 4D 风格 3D 模型
- 柔软橡胶、硅胶或 satin vinyl 材质
- 超细微纹理、细腻粗糙度变化和柔和边缘高光
- 鲜艳、干净、具有高级感的色彩
- 大面积柔光箱主光、宽幅补光和轻微轮廓光
- 明亮浅色背景、均衡曝光和精致的模型明暗层次
- 不添加落地阴影、暗色地面块或厚重接地效果

## 构图与视角

- 保留原照片的观察方向和构图关系
- 原图接近正面时，使用稳定的正面或近正面产品视角，不额外制造三分之四角度
- 原图确实有斜侧角度时，保留可见的正面、侧面和前后空间关系
- 使用平行透视修正梯形变形、倾斜垂直线和明显广角 distortion
- 使用更大的画布，让模型外轮廓与画面四条边之间至少保留 20% 的背景空间
- 模型保持居中、完整可见，但不应因为留白而缩得过小

## 限制

这个 Skill 依赖当前环境可用的图像生成或图像编辑能力。单张照片可以生成风格化的合理推测，但照片中不可见的侧面、背面或内部结构不一定是真实还原。

照片中的小字号文字可能无法逐字准确保留；Skill 会尽量保留其位置、层级和视觉形状，避免凭空生成确定内容。
